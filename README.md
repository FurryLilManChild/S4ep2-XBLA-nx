# S4ep2-XBLA-nx

A native Nintendo Switch (and PC) port of **Sonic the Hedgehog 4: Episode II** (Xbox 360 XBLA, 2012), made with
ReXGlue static recompilation, following [S4ep1-nx](https://github.com/FurryLilManChild/S4ep1-nx). Work in progress.

Not the mobile version's port: this one recompiles the Xbox 360 `default.xex`. No game data is included; you need your
own copy of the XBLA game.
